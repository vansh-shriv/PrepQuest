1. Sort the array.
2. For each position `i` (skip a value equal to the previous one): set `lo = i + 1`, `hi = n - 1`.
3. While `lo < hi`: look at the sum. If it is zero, record the triplet and move both pointers past equal values; if it is too small move `lo` right; if too large move `hi` left.
4. Return the recorded triplets.
