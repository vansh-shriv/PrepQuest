Return every **unique** triplet of values `[a, b, c]` that can be taken from three _different positions_ of `nums` and satisfies `a + b + c = 0`.

- Write each triplet in non-decreasing order (`a <= b <= c`).
- Do not list the same triplet twice, even if its values occur at several positions.
- List the triplets themselves in lexicographic order.

If there are none, return an empty array.
